# 📥 WORD-DOWNLOAD ANLEITUNG

## ⚡ SCHNELLSTE METHODE - Direkt in Word öffnen

### Schritt-für-Schritt (funktioniert auf JEDEM Windows-PC):

1. **Öffnen Sie Microsoft Word**

2. **Drücken Sie:** `Strg + O` (oder klicken Sie auf "Datei" → "Öffnen")

3. **Navigieren Sie zu Ihrem Projekt-Ordner:**
   - Wenn auf Desktop: `C:\Users\Nova\Desktop\EU-AI-ACT-claude-eu-ai-act-audit-tool-01SjaDDuGV1ZSj57VWwswAwe`
   - Oder wo auch immer Sie das Projekt haben

4. **WICHTIG:** Ändern Sie unten rechts den Dateityp von "Word-Dokumente" zu **"Alle Dateien (*.*)"**

5. **Wählen Sie eine dieser Dateien:**
   - `INVESTOR_PITCH_WORD.md` (Hauptpräsentation, 30+ Seiten)
   - `EXECUTIVE_SUMMARY.md` (1-Seite Summary)
   - `ONE_PAGER_INVESTOR.md` (Quick-Pitch)
   - `PITCH_DECK.md` (12-Abschnitte Pitch)

6. **Word öffnet die Markdown-Datei automatisch!**

7. **Jetzt speichern als .docx:**
   - `Datei` → `Speichern unter`
   - Format: "Word-Dokument (*.docx)"
   - Neuer Dateiname: z.B. "Investorenpitch.docx"

8. **FERTIG!** ✅

## 🌐 ALTERNATIVE 1 - Online-Konverter (keine Installation nötig)

### Methode A: MarkdownToWord.com

1. **Öffnen Sie im Browser:** https://www.markdowntoword.com/

2. **Öffnen Sie die Markdown-Datei mit einem Texteditor:**
   - Rechtsklick auf `INVESTOR_PITCH_WORD.md`
   - "Öffnen mit" → "Editor" oder "Notepad"

3. **Kopieren Sie ALLES** (Strg + A, dann Strg + C)

4. **Fügen Sie den Text auf der Website ein**

5. **Klicken Sie auf "Convert to Word"**

6. **Download** der .docx-Datei

---

### Methode B: Dillinger.io

1. **Öffnen Sie:** https://dillinger.io/

2. **Kopieren Sie den Inhalt** der Markdown-Datei (wie oben)

3. **Fügen Sie ihn links ein**

## 🎨 NACH DEM ÖFFNEN IN WORD - Formatierung verbessern:

### Empfohlene Anpassungen:

1. **Schriftart ändern:**
   - Überschriften: Arial Bold, 18-24pt
   - Text: Arial oder Calibri, 11-12pt

2. **Farben hinzufügen:**
   - Überschriften: Dunkelblau (#1E3A8A)
   - Wichtige Zahlen: Grün (#10B981)

3. **Seitenränder anpassen:**
   - Layout → Seitenränder → "Normal" (2,5 cm)

4. **Deckblatt erstellen:**
   - Einfügen → Deckblatt → Design wählen

5. **Inhaltsverzeichnis hinzufügen:**
   - Referenzen → Inhaltsverzeichnis → "Automatisch"

6. **Seitenzahlen einfügen:**
   - Einfügen → Seitenzahl → "Einfache Zahl"

## 🔍 FEHLERBEHEBUNG

### Problem: "Word kann die Datei nicht öffnen"

**Lösung:**
- Stellen Sie sicher, dass Sie "Alle Dateien (*.*)" als Dateityp gewählt haben
- NICHT "Word-Dokumente (*.docx)" - sonst sehen Sie die .md-Dateien nicht!

### Problem: "Formatierung sieht komisch aus"

**Lösung:**
- Das ist normal bei Markdown-Dateien
- Nutzen Sie die Online-Konverter oben
- Oder passen Sie die Formatierung manuell an (siehe oben)

### Problem: "Ich finde die Dateien nicht"

**Lösung:**
- Öffnen Sie Windows Explorer
- Navigieren Sie zu dem Ordner, wo Sie das Projekt gespeichert haben
- Suchen Sie nach "INVESTOR_PITCH_WORD.md"
- Oder benutzen Sie die Windows-Suche (drücken Sie Windows-Taste + S)

## 📊 EXCEL-FINANZMODELL ÖFFNEN

Für die Datei **FINANCIAL_MODEL.csv:**

1. **Rechtsklick** auf `FINANCIAL_MODEL.csv`

2. **"Öffnen mit" → "Microsoft Excel"**

3. **Automatische Konvertierung** erfolgt

4. **Formatieren:**
   - Zahlen als Währung: Wählen Sie Zahlen → Rechtsklick → "Zellen formatieren" → "Währung" → "€"
   - Charts erstellen (siehe PITCH_README.md für Vorschläge)

5. **Speichern als .xlsx:**
   - `Datei` → `Speichern unter` → "Excel-Arbeitsmappe (*.xlsx)"
